# TV Щит — блокувальник реклами для Android TV / Google TV

Блокує рекламу, трекери й телеметрію **в усіх додатках телевізора** через DNS-фільтр
(локальний VPN усередині ТВ, жодних сторонніх серверів).

## Як працює
- Через тунель іде **лише DNS**: відео, ігри та інший трафік ідуть напряму, швидкість не падає.
- Запити до рекламних доменів отримують `0.0.0.0`, решта йде на обраний DNS (Cloudflare / Google / Quad9 / AdGuard).
- Списки ті самі, на яких працює Brave / uBlock, тільки DNS-частина:
  - **AdGuard DNS filter** = EasyList + EasyPrivacy + AdGuard Base + Mobile Ads (з винятками `@@`, щоб нічого не ламалось)
  - **HaGeZi** (light / multi / pro)
  - **Perflyst SmartTV** — реклама і телеметрія смарт-ТВ
- Рівні: *Легкий* / *Стандарт* (рекомендовано) / *Максимум*.
- Списки вбудовані (працює одразу) і самі оновлюються раз на тиждень.
- Автозапуск після перезавантаження ТВ.
- «Щойно заблоковано»: якщо щось зламалось, вибери домен пультом і дозволь його.

## Обмеження (чесно)
- **YouTube**: рекламу в офіційному додатку не прибирає жоден DNS-блокувальник. Використовуй **SmartTube**
  (Downloader → код `28544`). Brave прибирає її інакше: змінює саму сторінку в браузері, а на ТВ так
  само робить SmartTube.
- Реклама, вбудована у відеопотік (IPTV, вшиті ролики), DNS-ом не блокується.
- Якщо на ТВ уже працює інший VPN, одночасно вони не працюватимуть.

## Як отримати APK

### Варіант А — GitHub (без встановлення програм)
1. Створи **публічний** репозиторій на github.com і завантаж туди вміст цієї папки
   (разом із прихованою папкою `.github`).
2. Вкладка **Actions** → збірка запуститься сама (~3–5 хв).
3. Готовий APK: `https://github.com/<ти>/<репозиторій>/releases/download/latest/TVShield.apk`

### Варіант Б — Android Studio на комп'ютері
Open → вибрати папку → Build → Build APK(s). Або в терміналі: `./gradlew assembleRelease`.

## Як встановити на ТВ
1. Встанови з Google Play додаток **Downloader** (AFTVnews).
2. Налаштування ТВ → Безпека → дозволь «Невідомі джерела» для Downloader.
3. У Downloader введи посилання на APK → встановити.
4. Відкрий **TV Щит** → «Увімкнути захист» → погодься на запит VPN.

Ключ підпису `app/tvshield.jks` лежить у проєкті, щоб оновлення ставились поверх старої версії.
